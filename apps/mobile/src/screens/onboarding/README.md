# screens/onboarding

The Volume III onboarding flow, in its specified order:

Welcome → Student profile → Connect Google Calendar → Connect Gmail → Connect Canvas → Add/confirm class schedule → Wake/sleep + meal routines → Commute assumptions → Goals → Hobbies/interests with desired frequency → Notification preferences → Privacy explanation → Build first plan → Today screen.

**Principles (Volume III):** show value before requesting broad permissions; explain why each integration is needed; allow skipping optional steps; generate the first useful plan immediately; infer and refine over time instead of a long configuration form.

**Note (Volume V, integration risk):** onboarding must deliver value from Calendar + Canvas alone — Gmail is enhancing, never blocking.
