# docs

`handbook/` is the canonical Saavii Handbook (Volumes I–V) — the single source of truth for this repository. Nothing elsewhere in the repo may contradict it; conflicts are surfaced, not silently resolved. Start at `handbook/README.md`.

`decisions/` holds decision records for choices the handbook deliberately leaves open. Every settled item in `ARCHITECTURE.md` §7 traces to either a handbook section or a record here.
